# Conventions

- Noms techniques en anglais, textes visibles en français.
- Fichiers et modules en `snake_case`.
- Classes Python en `PascalCase`.
- Une vue ne contient pas un traitement métier long : elle appelle un service.
- Éviter les suffixes `old`, `nouveau`, `final` et `sauvegarde`; utiliser Git.
- Un fichier ne doit avoir qu'une responsabilité principale.
- Les imports entre applications doivent rester limités et explicites.
