# Lot 3 — Ajustements visuels prudents

Modifications appliquées sans changement du contenu des pages :

- logo du bandeau commun agrandi d’environ 20 % ;
- pied de page raccourci à « © 2026 » ;
- feuille de style spécifique de la page Pompier rétablie ;
- aucune restructuration du contenu interne des pages.

Les suppressions de logos ou titres encore présents dans certaines pages seront réalisées page par page après validation visuelle.
