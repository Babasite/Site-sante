La note SPT (Santé Prévention Terrain)

Attention : la Santé humaine

Surveiller d'avantage les modes de vie, les inégalités et les risques environnementaux.

Comment améliorer la note ?

🧑 Améliorer sa santé humaine

Une courte orientation propre au pays.

  • Action prioritaire
  • Prévention concrète
  • Réduction d’une inégalité
  • Résultat attendu

🐾 Améliorer sa santé animale

Une courte orientation propre au pays.

  • Surveillance sanitaire
  • Prévention des zoonoses
  • Usage raisonné des antibiotiques
  • Protection de la faune

🌿 Améliorer ses écosystèmes

Une courte orientation propre au pays.

  • Restaurer les milieux
  • Réduire les pollutions
  • Préserver la biodiversité
  • Adapter les territoires

Sources utilisées

OMS, Banque mondiale, IHME, FAO, WOAH, IUCN, UNICEF, Copernicus, Reporters sans frontières, Transparency International.

Les biais

Disponibilité inégale des données selon les pays. Années de référence différentes selon les indicateurs. Méthodes de collecte pouvant varier entre les sources. Un indice synthétique simplifie une réalité complexe. Contraintes techniques du site ...

Pourquoi cette note ?

Chaque indicateur reçoit un score. Leur combinaison donne la note finale.
