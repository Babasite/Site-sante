Pack de sons universels arcade

Jeux visés : combat, Snake, Tetris, Space Invaders et mini-jeux.

Copiez les fichiers MP3 dans :
accueil/static/accueil/sons/

Noms utilisés par sons.js :
- clic.mp3 : tir, déplacement, validation ou action légère
- explosion.mp3 : impact, destruction, collision forte
- bonus.mp3 : objet ramassé, ligne complétée, combo
- bonne_reponse.mp3 : réussite
- mauvaise_reponse.mp3 : échec
- erreur.mp3 : action interdite ou collision légère
- chrono.mp3 : compte à rebours
- niveau.mp3 : manche, niveau ou vague suivante
- victoire.mp3 : victoire
- defaite.mp3 : défaite

Les WAV sont également inclus comme sauvegarde.
